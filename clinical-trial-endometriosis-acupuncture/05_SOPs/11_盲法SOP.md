## 1. 目的与设盲范围

本试验为**三臂**试验，盲法只存在于两个针刺臂之间（A 电针 vs B 假电针）；常规治疗臂（C）性质上不可设盲。

| 角色 | 是否设盲 | 说明 |
|---|---|---|
| A/B 臂受试者 | **是** | 研究结束前不告知具体分组 |
| C 臂受试者 | 否 | 知道自己未接受针刺 |
| 针灸医师 | 否 | 操作需要；不参与任何结局评估 |
| 结局评估者（QST 施测、问卷发放与访视）| **是** | 不得知晓任何患者的分组 |
| 研究协调员（排班、随机操作）| 否（知晓 A/B/C）| 不参与结局评估与 QST |
| 数据管理员 | **是** | 分配信息隔离存储 |
| 统计师 | **是**（主分析前组别以 X/Y/Z 编码）| SAP 签署后方可揭盲 |
| 安全监查员 | 按编码组别审查（半盲）| 必要时可申请揭盲 |
| PI | 是（除紧急揭盲外）| PI 不承担结局评估 |

> **设计边界的诚实声明**：本试验的主要对比（A vs C）本质上是**开放标签**的。这是 estimand 选择的直接后果——主 estimand 为"加用针刺的额外获益（effectiveness）"，其定义中本就包含非特异性成分。假针臂的作用是为该效应提供特异性成分的估计。本 SOP 保护的是 A vs B 的盲法。

## 2. 分组信息的隔离

| 信息 | 存放位置 | 可访问者 |
|---|---|---|
| 随机序列与种子 | 独立统计师封存（纸质 + 加密文件）| 独立统计师 |
| 备用密封信封 | 临床研究中心上锁柜 | 临床研究中心指定保管人 |
| IWRS 中的分配记录 | 系统数据库 | IWRS 管理员、协调员（仅本人操作的记录）、独立统计师 |
| 针灸科排班表 | 针灸科（仅列"受试者编号 + 治疗时段"，**不含组别**；组别由治疗者在治疗当日从系统中查询）| 针灸医师、协调员 |
| CRF 中的组别字段 | EDC，**对评估者角色隐藏** | 数据管理员按权限矩阵设置 |
| 分析数据集中的组别 | 编码为 X/Y/Z | 统计师（对应关系在揭盲时交付）|

**禁止**：在患者病历、检查申请单、微信群、排班白板、走廊交接记录中出现组别信息。

## 3. 物理与时间隔离

| 措施 | 规定 |
|---|---|
| 治疗时段 | A/B 臂尽量安排在不同时段；若必须同时段，使用独立诊床并以不透光屏风完全隔开，患者之间不能观察到对方的操作 |
| 候诊 | 避免 A/B 臂患者在同一候诊区长时间同处；到院后由协调员分批引导 |
| 治疗室标识 | 不得出现任何提示分组的标识（如"真针室""对照室"）|
| 器具准备 | 在患者视线之外完成（治疗车加盖或于准备间备好后推入）|
| 废弃物 | 真针与假针器具分别投放于不透明容器，患者不可见 |
| 患者之间的交流 | 知情同意与首次治疗时提醒："为了研究结果可靠，请不要与其他参加者讨论您接受的治疗细节。" |
| 患者与评估者 | 每次评估前由评估者说明："请不要向我描述您接受的治疗内容，这样我的评估才不会受影响。" |

## 4. 器具与仪器的外观一致性

| 项 | 要求 |
|---|---|
| 电针仪 | A/B 臂使用同型号、同外观的仪器；mock 装置的改装痕迹不可见（封记位于机身内侧或背面）|
| 指示灯与计时器 | mock 装置必须正常显示与倒计时 |
| 针具包装 | 假针器具在患者视野外拆封；粘贴底座与真针使用的胶布类型一致 |
| 器具数量 | 假针臂器具数量与"若为真针本应使用的处方"一致（含加减穴的镜像位点）|
| 消毒流程 | 两臂完全相同（假针臂即使不刺入亦照常消毒）|

## 5. 治疗者的语言纪律

治疗者是盲法的最大风险点。除 SOP 08/09 规定的统一脚本外：

**必须做**：
- 对两臂使用完全相同的问候、说明与告别用语；
- 对"有没有感觉"的回答统一为："有些人感觉明显，有些人几乎没有感觉，都是正常的。"

**禁止做**：
- 确认、否认或暗示分组；
- 对某一臂表现出更多的鼓励、安慰或额外的健康指导；
- 讨论其他患者的治疗反应；
- 在患者面前与同事讨论分组或研究结果；
- 对某一臂缩短或延长接触时间（目标差异 ≤5 分钟）。

**违反的处理**：治疗者自行或经他人发现后，当日填写《破盲事件报告表》（附录 B），由 PI 评估影响并记录；同一治疗者 2 次违反须重新培训，3 次违反须更换治疗者。

## 6. 结局评估者的操作规程

| 步骤 | 规定 |
|---|---|
| 1 | 评估者**不得进入治疗室**，不得查阅治疗记录表（CRF 模块 11）与针灸科排班表 |
| 2 | 评估顺序固定：先 QST（PPT → temporal summation），后问卷。理由：问卷内容可能引发患者提及治疗细节 |
| 3 | 评估前的标准开场白："我负责评估您的疼痛情况。为了保证评估客观，请不要向我描述您接受的治疗内容。如果您不小心提到了，也没有关系，我会如实记录。" |
| 4 | 若患者仍透露了治疗内容 → 在 CRF 的"评估者盲态声明"栏勾选"本次评估中评估者获知或推测了分组"，并简述情形。**如实记录，不隐瞒**；该记录用于 SAP §6 的敏感性分析 |
| 5 | 每次评估结束后，评估者在 CRF 中签署盲态声明（"本次评估时我不知晓该受试者的分组" / "我获知或推测了分组，情形如下"）|
| 6 | 评估者不参与排班、随机、治疗与 AE 处理 |

## 7. 盲法效果的评估

### 7.1 时点（**仅两次**）
| 时点 | 对象 | 施测方式 |
|---|---|---|
| 第 2 次治疗后 | A、B 臂 | 由不参与治疗的人员在治疗室外发放纸质问卷或经 ePRO 推送 |
| 第 12 周（V2）| A、B 臂 | 同上，在 QST 与其他问卷**完成之后**进行 |

**为什么只问两次**：2024 年针灸盲法系统综述（Systematic Reviews 2024，PMC11624600，VERIFIED-S）提示，**在研究进行中反复询问分组本身会增加去盲**。因此本研究严格限定为两个时点，其他任何访视、电话或治疗场合**均不得**询问患者对分组的猜测。

### 7.2 标准问题（逐字，中文）

> **问题 1**　您认为您接受的是哪一种针刺？（请选一项）
> ① 我肯定接受的是"真"的电针
> ② 我认为可能是"真"的电针
> ③ 我不知道 / 说不清
> ④ 我认为可能是"对照"的针刺
> ⑤ 我肯定接受的是"对照"的针刺
>
> **问题 2**　您这样判断的主要理由是什么？（可多选）
> □ 针刺时的酸胀麻感明显 / 不明显
> □ 有 / 没有电流的感觉
> □ 进针时的疼痛感
> □ 针的位置
> □ 治疗后症状的变化
> □ 医生的言行
> □ 其他（请说明）：__________
> □ 没有特别理由，是猜的

### 7.3 计算与报告
- **Bang 盲法指数（BI）**，按臂分别计算：
  `BI = (正确猜测人数 − 错误猜测人数) / 该臂应答总人数`（"不知道"计入分母）。取值 −1 至 +1；|BI| < 0.2 视为接近随机猜测；BI > 0.2 提示该臂患者倾向于猜对；BI < −0.2 提示倾向于猜错。
- **James 指数**（试验水平，0–1，0.5 = 完全随机）作为补充。
- 报告方式：按臂、按时点、并**按既往针灸经验分层**（本研究的核心方法学关注点）；给出 95% CI；同时报告猜测理由的分布。
- 计算工具：R 包 `BI`；分析代码纳入版本控制。

### 7.4 盲法失败时的处理（**预先声明，不得事后决定**）
若 A 臂 BI > 0.2 且 B 臂 BI < −0.2（即患者能够识别分组）：
1. 在论文中把 A vs B 的比较明确解释为"**在盲法不完全条件下的估计**"；
2. 执行 SAP §6 的敏感性分析 S5（把第 12 周分组猜测作为协变量）与 S6（校正基线期待 AES 与可信度 CEQ）；
3. **不更换主要终点，不取消假针臂，不因此改变分析计划**；
4. 与假针可信度预试验的数据合并，形成方法学论文。

## 8. 紧急揭盲

| 项 | 规定 |
|---|---|
| 何时可揭盲 | 仅当受试者发生**需要知晓分组才能处置**的医学紧急情况（实际上针刺研究极少需要）；或监管/伦理要求 |
| 谁可申请 | 主管医师或 PI |
| 谁执行 | PI 通过 IWRS 的紧急揭盲功能；PI 不可及时由临床研究中心指定负责人使用备用信封 |
| 记录 | 24 小时内填写《紧急揭盲记录表》（附录 C）：时间、申请人、理由、揭盲范围（仅限必要人员）、对研究的影响评估；报伦理委员会 |
| 后果 | 该受试者继续随访并保留在 ITT 分析中；在 CONSORT 流程图与论文中报告揭盲例数与原因 |
| 禁止 | 因患者好奇、研究者好奇、或"想看看有没有效果"而揭盲 |

## 9. 统计师的盲态与最终揭盲

1. 数据管理员在导出分析数据集时将组别编码为 **X / Y / Z**（对应关系由数据管理员单独保管，不告知统计师）；
2. 统计师完成盲态数据审查会议、确认分析人群与协变量形式；
3. **SAP 最终版由统计师与 PI 签署并存档**；
4. 数据库锁定；
5. 数据管理员向统计师交付 X/Y/Z 与 A/B/C 的对应关系（书面，存档）；
6. 执行主分析。

**顺序不可颠倒**：任何在 SAP 签署与数据库锁定之前的揭盲都必须作为重大方案偏离上报伦理委员会，并在论文中披露。
