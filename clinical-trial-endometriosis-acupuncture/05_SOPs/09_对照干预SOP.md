# 第一部分　假电针臂（B 臂）操作规程

## 1. 原则

假电针臂的唯一目的是**在保留全部非特异性成分（往返医院、躺卧、医患接触、治疗仪式、期待）的前提下，去除针刺的特异性刺激**。因此：

- 除"针是否刺入、位置是否为穴位、电针仪是否输出电流"三点外，**B 臂的一切都必须与 A 臂完全相同**：治疗室、体位、消毒、器具外观与数量、留针时长、治疗者、交流脚本、治疗频次与窗口、AE 询问方式。
- 治疗者**不得**以任何方式暗示患者所在组别，包括语气、操作速度、额外的解释或安慰。

## 2. 器具

### 2.1 默认方案：非穿刺伸缩式假针
| 项 | 规定 |
|---|---|
| 类型 | Park 型或 Streitberger 型非穿刺伸缩式假针（钝头；施加压力时针体缩入针柄，外观上"变短"，模拟进针）|
| 固定 | 配套粘贴底座（导管座）固定于皮肤表面 |
| 数量 | 与该患者"若为真针本应使用的处方"数量一致（核心 9 枚；若辨证本应加 1–2 穴，则在对应的镜像非穴位加放同等数量），**使患者可见的器具数量与 A 臂无差异** |
| 采购 | 【待针灸科确认供货渠道与型号】——可能需进口，须在启动前 3 个月完成采购验证 |
| 依据 | 2024 年针灸盲法系统综述（Systematic Reviews 2024, PMC11624600，VERIFIED-S）：亚洲人群、**穿刺性假针**、研究中反复询问分组三者均增加去盲；MacPherson 2014（VERIFIED-S 定性）：穿刺性假针压缩真/假差异；Park 2002（PMID 12512790，VERIFIED-S）：58 例卒中患者中无人认为自己接受的是假针；Enblom 2011（PMID 21747890，VERIFIED-S）：伸缩式假针的盲法效果**不受既往针灸经验影响**（对既往针灸暴露率高的中国患者尤为重要）|

### 2.2 备选方案：浅刺非穴位（**仅在预试验决策规则触发时启用**）
| 项 | 规定 |
|---|---|
| 针具 | 与 A 臂同型号 0.25×40 mm 一次性毫针 |
| 深度 | 2–3 mm，不行针、不求得气 |
| 位置 | 与默认方案相同的非穴位点 |
| 启用条件 | 预试验中非穿刺假针不满足预设成功标准而浅刺假针满足；或器材确实无法采购（须经 PI 与伦理委员会书面确认并作为方案修订）|

## 3. 非穴位选点规则

| 规则 | 内容 |
|---|---|
| 距离 | 距任何已知经穴、经外奇穴 ≥1.5 cm |
| 经线 | 不位于任何经脉循行线上 |
| 对应 | 与 9 个真穴一一对应（同侧、邻近区域），使器具的空间分布在视觉上与 A 臂相似 |
| 安全 | 避开大血管、神经干、皮肤破损处 |
| 示意图 | 【待针灸科确认】——由针灸科 Co-PI 与 ≥2 名高年资医师共同确定并绘制标准示意图，作为本 SOP 附录 A，定稿前不得启动入组 |

## 4. mock 电针（假电针）设置

### 4.1 装置要求
| 项 | 规定 |
|---|---|
| 外观 | 与 A 臂使用的电针仪**型号相同、外观一致** |
| 运行表现 | 开机、指示灯点亮、计时器正常倒计时、旋钮可转动、如有声音提示则正常发声 |
| 输出 | **为零**。通过以下两种方式之一实现：<br>① 专用 mock 装置（内部断开输出回路，由设备科改装并加封记，外观与功能显示完全保留）；<br>② 输出导线在仪器端断开并以不透明封套固定（每次治疗前确认封记完好）|
| 标识 | mock 装置以内部编号区分（如 EA-M01），**不得**在患者可见处标注"假"或"sham" |

### 4.2 零输出验证
| 频率 | 操作 | 记录 |
|---|---|---|
| 每次治疗前 | 目视确认封记完好、指示灯与计时器正常 | 治疗记录表勾选 |
| **每周一次** | 用测试仪（万用表/示波器）在标称最大输出下测量导线端电压/电流，确认为零 | 《mock 电针零输出核查表》（附录 B），由针灸科负责人签字 |
| 每次维修或更换后 | 重新验证并记录 | 同上 |

### 4.3 强度"调节"脚本
治疗者需按与 A 臂相同的节奏进行"调节"动作并说明：

> "现在开始通电，我慢慢调大，您感觉到明显但还舒服的时候告诉我。"
> （转动旋钮，观察患者反应）
> "好，就到这里。**有些人会有明显的感觉，有些人几乎没有感觉，这两种情况都是正常的。**"

- 在治疗记录中，B 臂的"强度"栏记录为"mock，旋钮位置读数 ____"，**不记录 mA**（无实际输出）；
- 治疗者**不得**说"这个应该有感觉"或"没感觉说明没接好"。

## 5. 治疗流程（与 SOP 08 逐步对应）

| 步骤 | A 臂（真电针）| B 臂（假电针）|
|---|---|---|
| 1 核对身份与分组 | 相同 | 相同 |
| 2 禁忌复核清单 | 相同 | 相同 |
| 3 体位（仰卧）与暴露 | 相同 | 相同 |
| 4 皮肤消毒 | 相同 | 相同（即使不刺入也照常消毒）|
| 5 定位 | 9 个核心穴 | 9 个对应非穴位 |
| 6 置针 | 进针至规定深度 | 放置伸缩式假针于粘贴底座，加压至针体缩入 |
| 7 得气 | 提插捻转至得气并记录 | **不行针、不求得气**；停留同等时间以匹配操作时长 |
| 8 电针连接 | 2 对导联，2/100 Hz，30 min | 同样位置连接 2 对导联，仪器开机，**无输出**，30 min |
| 9 强度调节 | 滴定至"明显但舒适"，记录 mA | 按脚本执行调节动作，记录旋钮读数 |
| 10 留针 30 min | 相同 | 相同 |
| 11 第 15 分钟中途查看 | 相同 | 相同 |
| 12 出针/移除 | 出针、按压止血 | 移除假针与底座、按压贴附处 |
| 13 AE 询问 | 相同 | 相同 |
| 14 记录 | CRF 模块 11 | CRF 模块 11 |
| 15 预约下次 | 相同 | 相同 |

**总接触时长必须相当**（目标差异 ≤5 分钟）；由保真度核查抽查确认。

## 6. 患者告知语（统一，两臂通用）

首次治疗前由治疗者说明：

> "本研究比较两种针刺方式。您接受的是其中一种，在研究结束前我和您都不会讨论具体是哪一种。**两种方式的针感和电刺激感觉可能明显，也可能很轻甚至几乎没有，这都是正常的，不代表治疗是否有效，也不代表您在哪一组。**如果您感到任何不适，请随时告诉我。"

若患者追问分组：

> "我理解您想知道。按照研究规定，这一点在研究结束前需要保密，这样才能保证结果可靠。研究全部结束后我们会告诉您。您现在感觉怎么样？"

**禁止**的回应：确认或否认；暗示"您这组感觉会强一些"；讨论其他患者的情况。

## 7. B 臂的不良事件

预期 AE 与处理见 SOP 12。B 臂特有的可能事件：粘贴底座处皮肤发红、瘙痒或胶布过敏（处理：移除、局部清洁、必要时更换低敏胶带并记录；反复过敏者与 PI 讨论是否改用其他固定方式或终止治疗）。

## 8. B 臂的记录要点（CRF 模块 11）
治疗序号、日期、窗口合规、所用非穴位点（与镜像处方一致性）、器具数量、假针型号与批号、mock 装置编号、封记完好确认、旋钮读数、留针时长、治疗者 ID、脚本合规、当次 AE、偏离。

# 第二部分　常规治疗臂（C 臂）操作规程

## 1. "常规治疗"的定义

C 臂患者继续接受龙华医院对内异症术后患者的**指南推荐标准管理**，具体包括（按其入组时已在使用的方案继续）：
- 激素治疗：GnRH-a（± 反加）、地诺孕素、复方口服避孕药、LNG-IUS、其他孕激素，或经医生评估的无激素治疗；
- 中药：包括院内制剂（如琥黄异位片）与个体化汤剂，按其原有方案继续；
- 镇痛药：按需使用；
- 常规妇科随访。

**研究不干预临床用药决策。**如主治医生因病情需要调整方案，照常调整并记录（按 treatment policy 策略分析）。

## 2. 研究期间的禁止事项（0–24 周）

C 臂患者在随机后至第 24 周随访完成前，**不得接受任何针灸类治疗**，包括：
针刺、电针、经皮穴位电刺激（TEAS）、穴位埋线、耳针/耳穴压豆、艾灸、拔罐（针对盆腔痛的治疗性使用）。

- 在知情同意与每次接触时重申；
- 每周 ePRO 设"本周是否在研究外接受过针灸类治疗"必答项；
- 若发生：**不终止其研究参与**，如实记录（时间、类型、次数、场所），按 treatment policy 保留在 ITT 分析中，并在 PP 分析中排除。

## 3. 接触安排（第 4、8、12、24 周）

| 时点 | 方式 | 时长 | 内容 |
|---|---|---|---|
| 第 4 周 | 电话或微信语音 | ≤10 分钟 | 标准脚本 |
| 第 8 周 | 电话或微信语音 | ≤10 分钟 | 标准脚本 |
| 第 12 周 | 门诊（V2 访视）| 按 V2 安排 | 问卷 + QST + AE |
| 第 24 周 | 门诊（V3 访视）| 按 V3 安排 | 问卷 + QST + AE + 安排延迟治疗 |

### 3.1 电话接触标准脚本（第 4、8 周）

> "您好，我是龙华医院妇科研究团队的【姓名】。按照研究安排，我今天和您联系，了解一下情况，大约 10 分钟。
> ① 这段时间您的手机问卷填写还顺利吗？有没有遇到困难？
> ② 您目前的用药有没有变化？（记录）
> ③ 有没有出现任何不舒服或身体不适？（记录 AE）
> ④ 有没有在其他地方做过针灸、艾灸、埋线之类的治疗？（记录）
> ⑤ 提醒您：第【12/24】周我们会请您来医院做一次评估，大约 45 分钟，我们会提前预约。
> 谢谢您的配合。如果有任何问题随时联系我。"

**不得**在接触中：提供针对疼痛的治疗建议、评价其他组的治疗、暗示其"吃亏"或"占便宜"、进行任何形式的心理干预或健康教育（除安全相关提示外）。**这是为了避免 C 臂接受一种未计划的干预，从而破坏对照的意义。**

若患者主动询问疼痛处理：

> "关于您疼痛的处理，请以您主治医生的意见为准，我可以帮您预约门诊。研究本身不改变您的治疗方案。"

若发现安全问题（新发剧烈疼痛、发热、异常出血、情绪危机等）：立即按 SOP 12 处理并转诊。

## 4. C 臂的保留策略（针对退出风险）

C 臂是本试验保留率风险最高的一组。措施：
1. **延迟治疗承诺**：知情同意与每次接触时明确重申"第 24 周随访完成后免费提供 20 次电针"；
2. **等量接触**：与 A/B 臂相同频率的联系（虽不做治疗）；
3. **交通补贴**：V2、V3 访视同样发放；
4. **ePRO 提醒与补救**：与其他组相同；
5. **表达感谢**：接触脚本中明确说明其数据的价值；
6. 协调员每月检查 C 臂 ePRO 完成率，低于 80% 者优先电话跟进。

## 5. 延迟电针疗程（V3 后）

| 项 | 规定 |
|---|---|
| 资格 | 完成 V3 访视的 C 臂患者（含中途停止 ePRO 但完成 V3 者）|
| 方案 | 与 A 臂完全相同的 20 次电针（SOP 08），由同一组针灸医师实施 |
| 费用 | 免费（由研究经费或医院承担）|
| 时限 | V3 后 3 个月内开始，6 个月内完成 |
| 数据 | 记录治疗完成情况与 AE（进入安全性汇总）；**不进入任何疗效分析** |
| 拒绝 | 患者可拒绝，记录并不影响其已完成的研究参与 |
| 说明 | 延迟疗程期间不再采集疗效 ePRO（第 25–52 周的每月问卷照常，分析中标注该臂已接受治疗）|

> **分析注意**：C 臂在第 24 周后接受电针，因此**第 52 周的探索性分析中，C 臂不再是未治疗对照**。SAP 与论文必须明确说明这一点。

# 第三部分　假针可信度预试验（EASE-Sham Pilot）操作规程

## 1. 目的
在正式 RCT 启动前，确定哪一种假针方案在本院患者中**盲法效果更好且可信度不低于真针**，并检验相关流程。

## 2. 设计
| 项 | 规定 |
|---|---|
| 样本量 | n = 30（每组 10 例）|
| 对象 | 符合 EASE-PPP 主要纳入标准的患者（可放宽 NRS 阈值至 ≥3），单独知情同意 |
| 分组 | 1:1:1 随机：① 真电针；② 非穿刺伸缩式假针 + mock EA；③ 浅刺非穴位（2–3 mm）+ mock EA |
| 分层 | 既往针灸经验（有/无）|
| 治疗 | 每人 **2 次**（间隔 2–7 天），操作与正式研究完全一致 |
| 盲法 | 患者设盲；评估问卷由不参与治疗的人员发放 |

## 3. 结局
| 结局 | 工具 | 时点 |
|---|---|---|
| 主要 | 分组猜测（Bang 5 类问题）+ 猜测理由 | 第 2 次治疗后 |
| 主要 | 治疗可信度与期待（CEQ 6 项）| 第 2 次治疗后 |
| 次要 | 针刺期待（AES 4 项）| 基线与第 2 次治疗后 |
| 次要 | 针感问卷（酸、麻、胀、重、刺痛、电流感，各 0–10）| 每次治疗后 |
| 次要 | AE | 全程 |
| 过程 | 器具放置耗时、脱落率、患者主诉 | 每次治疗 |

## 4. 预设成功标准
一个假针方案被判定为"可用"，须**同时**满足：
1. 该假针臂的 **Bang 盲法指数在 −0.2 至 +0.2 之间**（即患者猜测接近随机）；
2. 该假针臂的 **CEQ 可信度均分与真电针臂之差 <1 分**（在 CEQ 的原始量表尺度上）。

## 5. 决策流程（文字流程图）

```
两种假针方案的 BI 与 CEQ 结果
        │
        ├─ 非穿刺假针满足两条标准？
        │        │
        │        ├─ 是 ──► 采用非穿刺假针（默认方案）→ 正式 RCT 启动
        │        │
        │        └─ 否 ──► 浅刺假针满足两条标准？
        │                      │
        │                      ├─ 是 ──► 改用浅刺假针（须报伦理委员会备案，
        │                      │          并在方案与注册中更新）
        │                      │
        │                      └─ 否 ──► 两者均不满足
        │                                   │
        │                                   ▼
        │            仍采用非穿刺假针启动 RCT，但同时：
        │            ① 在方案与注册中预先声明盲法可能不完全；
        │            ② 预设"分组猜测校正分析"（SAP §6 S5）；
        │            ③ 在论文中把 A vs B 的比较解释为
        │               "在盲法不完全条件下的估计"；
        │            ④ 不因此更换主要终点或取消假针臂。
```

**同时满足者若为两个方案**：优先采用非穿刺假针（更接近惰性对照，且不涉及穿刺风险）。

## 6. 预试验的其他产出
- 器具操作耗时与流程瓶颈 → 用于优化正式研究的排班；
- 针感问卷的分布 → 用于正式研究中"针感"次要指标的预期；
- 治疗者对脚本的执行情况 → 用于强化培训；
- 预试验结果连同正式 RCT 的盲法数据，可合并形成一篇方法学论文。

## 7. 伦理与注册
独立的伦理申请与知情同意书（`04_ICF/07_知情同意书.md` 第二部分）；建议一并在 ChiCTR 注册（可作为主研究的子研究登记）。
