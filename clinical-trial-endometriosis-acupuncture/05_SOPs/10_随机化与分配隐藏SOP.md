## 1. 目的

1.1 规定 EASE-PPP 随机序列（randomization sequence）的生成、封存、实施、备用方案、质控与偏离处理，确保：
- **分配隐藏（allocation concealment）**：任何可能影响入组决定的人员在受试者被随机之前，无法预知或推测下一例的分组；
- **分配不可更改（irreversibility）**：分配一经产生即带时间戳固化，不得事后修改、撤回或调换；
- **盲法可维持**：随机化环节本身不成为去盲（unblinding）的来源。

1.2 本 SOP 适用于 EASE-PPP 主试验的全部 210 例（上限 240 例）随机化操作。EASE-Sham Pilot（假针可信度预试验，n=30，1:1:1）另按其简化随机流程执行，其序列由同一独立统计师生成、单独封存，不与主试验序列混用。

1.3 阅读对象：独立统计师、IWRS 管理员、研究协调员（CRC）、妇科研究医师、PI、数据管理员、针灸排班员。**盲态评估者（blinded outcome assessor）与盲态统计师不需要、也不得阅读本 SOP 的附录 A2/A3 内容以外的实施细节以外部分**（见 7.2）。

### 2.1 四个分层（strata）清单

| 层号 | CSI | 激素抑制治疗 | 层代码 |
|---|---|---|---|
| S1 | ≥40 | 是 | `CSIH_HORMY` |
| S2 | ≥40 | 否 | `CSIH_HORMN` |
| S3 | <40 | 是 | `CSIL_HORMY` |
| S4 | <40 | 否 | `CSIL_HORMN` |

**分层变量的可操作定义**

- **CSI**：采用 CSI 中文版 Part A（25 条目，0–100 分），于 **V1 随机前**由受试者自填、盲态评估者收集并当场录入 EDC；分层阈值 **40**（≥40 为高中枢敏化）。允许缺失条目 ≤2 条时按已答条目均值补齐后取整（此规则同步写入 SAP）；缺失 ≥3 条不得随机，须当日补齐。
- **激素抑制治疗 = 是**：随机时正在使用下列任一且随机前 ≥8 周方案未变更——促性腺激素释放激素激动剂（GnRH-a，含反向添加 add-back）、地诺孕素（dienogest, DNG）、复方口服避孕药（combined oral contraceptive, COC）、左炔诺孕酮宫内缓释系统（LNG-IUS）、其他孕激素。
- **激素抑制治疗 = 否**：以上均未使用（须在 CRF 记录无激素治疗的原因：不耐受／禁忌／拒绝／生育计划已完成／其他）。
- 判定人：**妇科研究医师**，依据合并用药表（CRF 模块 07）与门诊病历，随机申请前签名确认；CRC 不得自行判定。

### 2.2 为什么区组长度必须是 5 的倍数

- 分配比 A:B:C = 2:2:1，**比值之和 = 5**。只有当区组长度为 5 的整数倍时，区组内才能同时满足 2:2:1 的精确构成；任何非 5 倍数的长度（如 4、6、8）都会在区组内产生比例失真，破坏"每完成一个区组即恢复 2:2:1"的平衡性质。
- 因此本研究仅允许两种区组：
  - **区组长度 5** → 构成 A×2、B×2、C×1；
  - **区组长度 10** → 构成 A×4、B×4、C×2。
- **两种长度按等概率随机混合**（每个新区组以 0.5 概率取 5、0.5 概率取 10），目的是防止不设盲的针灸医师、排班员或协调员通过计数已分配例数推断区组末位（"区组末端可预测性"，block-end predictability）。
- 由于分层随机在 4 个层内独立进行，连续入组的受试者通常落在不同层的不同区组，进一步降低可预测性。
- **区组长度、区组编号与区组内构成属于分配隐藏信息**，不得写入方案、ICF、注册信息、任何培训材料或对外发表的方法学描述（发表时只写"随机区组长度不予披露/为 5 与 10 的随机混合，且在试验结束前不对研究团队披露"）。
- 允许试验结束时各层末尾出现**不完整区组**（数据锁定时各臂实际例数与 84/84/42 可略有出入），这是分层区组随机的正常表现，不构成方案偏离。

## 3. 随机序列生成

### 3.1 生成人与独立性

- 由**独立统计师（independent statistician）**生成。独立统计师：隶属临床研究中心，**不参与受试者招募、干预实施、结局评估与主分析**；与 PI 及针灸科无从属关系；在《角色与利益冲突声明》上签字备案。
- 主分析统计师（盲态统计师）**不得**参与序列生成，也不得接触未编码的分配数据（见 SOP 11）。

### 3.2 生成参数（冻结）

| 参数 | 取值 |
|---|---|
| 臂与代码 | A / B / C（写入序列文件；对外输出时由 SOP 11 映射为 X/Y/Z） |
| 分配比 | 2:2:1 |
| 区组长度 | 5 或 10，每区组等概率随机抽取 |
| 层 | 4 层（见 §2.1），各层独立生成 |
| 每层生成分配位数 | **≥120**（仅保留完整区组；4 层合计 ≥480 个分配位，远超样本量上限 240，确保任一层不会耗尽） |
| 补充生成触发 | 任一层剩余未用分配位 <10 时，独立统计师按本 SOP 追加生成一段并加封（记录于附录 A3） |
| 随机种子 | 生成当日由独立统计师现场产生（例如 `sample(1e8, 1)`），**不写入本 SOP、方案或任何流通文件**，仅记录于密封的《随机化种子与序列封存记录》 |

### 3.3 R 代码框架（基础 R 版本，推荐；完全可审计）

```r
## EASE-PPP 随机序列生成脚本 v1.0  —— 由独立统计师执行，脚本与输出一并封存
## 环境：R >= 4.3.0；输出：sessionInfo() 一并存档
rm(list = ls())

## ---- 0. 种子（占位符）--------------------------------------------------
## 实际执行时用现场产生的随机整数替换 <SEED>，并将其记录在
## 《随机化种子与序列封存记录》（纸质，密封，临床研究中心保险柜）
SEED <- <SEED>          # 例：set.seed(sample(1e8, 1)) 产生后回填
set.seed(SEED)

## ---- 1. 参数 -----------------------------------------------------------
strata      <- c("CSIH_HORMY", "CSIH_HORMN", "CSIL_HORMY", "CSIL_HORMN")
block_sizes <- c(5L, 10L)      # 仅允许 5 的倍数（2+2+1=5）
block_prob  <- c(0.5, 0.5)     # 两种长度等概率
n_per_str   <- 120L            # 每层至少生成的分配位数（只保留完整区组）

## ---- 2. 单个区组 -------------------------------------------------------
make_block <- function(size) {
  stopifnot(size %% 5L == 0L)
  k <- size %/% 5L
  sample(rep(c("A", "A", "B", "B", "C"), times = k))   # 区组内随机排列
}

## ---- 3. 单层序列（只保留完整区组，绝不截断）---------------------------
gen_stratum <- function(stratum, n_min) {
  out <- data.frame()
  blk <- 0L
  while (nrow(out) < n_min) {
    blk  <- blk + 1L
    size <- sample(block_sizes, 1L, prob = block_prob)
    out  <- rbind(out, data.frame(
      stratum    = stratum,
      block_id   = blk,
      block_size = size,
      arm        = make_block(size),
      stringsAsFactors = FALSE))
  }
  out$slot <- seq_len(nrow(out))                    # 层内分配位序号，从 1 起
  out[, c("stratum", "slot", "arm", "block_id", "block_size")]
}

## ---- 4. 全部四层 -------------------------------------------------------
seq_all <- do.call(rbind, lapply(strata, gen_stratum, n_min = n_per_str))
rownames(seq_all) <- NULL

## ---- 5. 生成质控（必须全部为 TRUE / 通过后方可交付）-------------------
stopifnot(all(seq_all$block_size %% 5L == 0L))                 # 区组长度合法
chk <- aggregate(arm ~ stratum + block_id, data = seq_all,
                 FUN = function(x) paste(sort(x), collapse = ""))
## 每个完整区组必须是 AABBC(排序后) 或 AAAABBBBCC(排序后)
stopifnot(all(chk$arm %in% c("AABBC", "AAAABBBBCC")))
print(table(seq_all$stratum, seq_all$arm))                     # 每层 A:B:C≈2:2:1
print(table(seq_all$block_size))                               # 5/10 混合比例

## ---- 6. 交付物 ---------------------------------------------------------
## (a) IWRS 导入文件（含 arm，加密）；(b) 信封打印文件（含 arm，加密）；
## (c) 生成日志（脚本 + sessionInfo + 质控输出，不含 arm 可对外留存）
write.csv(seq_all, "EASEPPP_randlist_v1.0_CONFIDENTIAL.csv", row.names = FALSE)
writeLines(capture.output(sessionInfo()), "EASEPPP_randlist_sessionInfo.txt")
```

### 3.4 R 代码框架（`blockrand` 备选版本）

`blockrand` 包本身面向等比例分配；对 2:2:1 可用**水平向量重复**的写法实现（`levels` 内重复 A、B 各两次、C 一次，`num.levels = 5`，则 `block.sizes = 1` 与 `2` 分别给出长度 5 与 10 的区组）：

```r
library(blockrand)                       # 记录包版本于生成日志
set.seed(SEED)
lv <- c("A", "A", "B", "B", "C")         # 2:2:1
one <- function(st) {
  r <- blockrand(n = 120, num.levels = length(lv), levels = lv,
                 block.sizes = c(1, 2),   # 实际区组长度 = 1*5=5 或 2*5=10
                 stratum = st, id.prefix = st, block.prefix = st)
  r
}
seq_all <- do.call(rbind, lapply(strata, one))
## 必须执行与 §3.3 第 5 步相同的质控（区组构成 AABBC / AAAABBBBCC）后方可交付
```

> **注意**：使用 `blockrand` 时 `num.levels` 必须等于 `length(lv)`（此处为 5），否则区组长度记录会失真。无论采用哪个版本，**§3.3 第 5 步的三项质控输出必须打印、签名并封存**。

### 3.5 种子与序列的封存

1. 独立统计师在**单机、无网络**环境运行脚本；输出文件即时以 AES-256 加密（口令仅独立统计师持有）。
2. 交付物三份：
   - **加密序列文件（含 arm）** → 上传 IWRS（由 IWRS 管理员在系统内导入，导入后不可导出明文）；
   - **加密序列文件（含 arm）** → 用于打印备用信封（§5）；
   - **生成日志（脚本、`sessionInfo()`、质控输出，不含 arm）** → 存入试验主文档（Trial Master File, TMF）。
3. **《随机化种子与序列封存记录》**（纸质）：记录种子值、生成日期时间、软件与包版本、文件 SHA-256 校验值、每层分配位数、独立统计师签名、临床研究中心负责人见证签名 → 密封信封 → 临床研究中心保险柜，**封至数据库锁定并完成主分析后**由 PI 与临床研究中心共同启封。
4. 序列明文不得通过电子邮件、微信、共享盘或任何即时通讯工具传递。

| 研究协调员（CRC） | 发起随机申请、录入层次、查看随机结果的**受限视图** | 受试者号、随机日期时间、层次、**"针刺组（A/B 之一）"或"常规治疗组（C）"**；不可见 A/B 之分 |

> **设计说明**：C 臂为开放（open-label），CRC 必然知晓某受试者是否需要预约针刺，因此 CRC 的受限视图只区分"针刺组 / 常规治疗组"，**不区分 A 与 B**，以最大限度保护 A/B 盲法。此为冻结表 §5"盲：患者（A vs B）……"的实施细化，不改变冻结项。

### 4.2 随机操作步骤（必须按序执行，IWRS 逐步强制）

**步骤 1｜资格确认（Eligibility confirmation）**
- 妇科研究医师在 EDC 完成纳入 9 条 / 排除 10 条逐条勾选并电子签名；
- IWRS 校验 EDC 返回的资格状态 = "合格"；任一条不满足则随机按钮灰显。

**步骤 2｜层次录入（Stratum entry）**
- CRC 录入：CSI 总分（0–100，系统自动派生 ≥40/<40）与 激素抑制治疗（是/否，须与 CRF 模块 07 合并用药表一致）；
- IWRS 自动生成层代码并回显给 CRC 确认；**层次一经提交不可修改**（如需更正见 §7.2）。

**步骤 3｜基线 QST 与问卷完成校验（硬性前置条件）**
- IWRS 在分配前强制校验 EDC 中 V1 记录的下列条目状态均为"完成"：
  - **定量感觉测试（quantitative sensory testing, QST）**：压痛阈（pressure pain threshold, PPT）4 个部位（双侧下腹脐下 4 寸旁开 3 寸、双侧胫前肌远端）各 3 次读数齐全；时间总和（temporal summation, TS）末次−首次 NRS 已记录；
  - **全套基线问卷**：CSI、疼痛灾难化量表（PCS）、PHQ-9、GAD-7、ISI（3 项简版）、EHP-30、BPI-SF 干扰域、widespread pain 人体图、针刺期待量表（Acupuncture Expectancy Scale, AES）、既往针灸经验；
  - **筛选期 2 周每周 NRS**：2 次均已提交且均 ≥3、均值 ≥4。
- 任一项未完成 → 系统拒绝分配并提示缺失项。
- **理由**：① CSI 是分层变量，必须先测；② 全部基线测量（尤其 QST 与期待量表）必须在受试者与评估者均不知分组的状态下完成，否则基线值本身被分组预期污染，主分析的 ANCOVA 基线协变量将失去可比性。**任何情况下不得"先随机、后补基线"**。

**步骤 4｜时间戳分配（Time-stamped allocation）**
- CRC 点击"确认随机"；IWRS 在该层内取**最小未使用分配位**，写入：受试者号（EASE-XXX，系统按入组顺序连续生成）、层代码、层内分配位序号、arm、服务器时间戳（精确到秒，UTC+8）、操作者账号、IP/终端标识；
- 记录一经写入即**只读**，任何角色不可编辑或删除（数据库层面强制）；
- 系统即时向 CRC 返回受限视图（受试者号 + "针刺组"/"常规治疗组" + 随机日期时间），并生成随机确认单（PDF）存 EDC 与 TMF。

**步骤 5｜仅通知针灸排班员（Restricted notification）**
- IWRS 通过系统内消息（非邮件、非微信）将 **A 或 B** 仅推送给**针灸排班员**账号；
- 针灸排班员据此排班并准备器材（A：常规毫针 + 电针仪；B：非穿刺伸缩式假针 + mock 装置），在治疗当日于治疗室内口头告知当班针灸医师，**不得在公共区域、微信群、纸质排班表或电子病历中书写 A/B**；
- 排班表对 CRC 与患者显示统一格式"针刺治疗，X 月 X 日 X:XX，X 诊室"，不含臂信息；
- C 臂：IWRS 不推送针灸排班，CRC 按 SOP 09 安排第 4、8、12、24 周接触，并登记 24 周后的延迟治疗（deferred treatment）预约意向。

### 4.3 随机与首次治疗的时间要求

- 随机应在 V1 当日完成；A/B 臂首次治疗于**随机当日或 3 天内**实施（冻结表 §8）。
- 若随机后 3 天内因不可抗力未能开始治疗，记录为方案偏离（轻微/重大由 PI 判定），**不重新随机**。

### 4.4 系统验证要求

- IWRS 上线前须完成用户需求说明（URS）、安装/运行/性能确认（IQ/OQ/PQ）与用户验收测试（UAT），测试用例至少覆盖：分配比与区组构成、4 层独立取号、基线未完成时的拦截、并发随机（两台终端同时提交同一层）、断网/超时后的幂等性（不得产生双重分配）、审计轨迹完整性、权限越权尝试被拒。
- 测试用例、测试数据（使用虚拟序列，**不得使用正式序列**）与验证报告存 TMF。
- 正式序列导入后执行"导入核对"：由独立统计师核对系统内各层分配位总数与文件 SHA-256 一致，签字确认（附录 A1 步骤 0）。

## 5. 备用密封信封（仅 IWRS 故障时）

### 5.1 制作规格

| 项目 | 规格 |
|---|---|
| 材质 | **不透光**信封（内衬碳纸/铝箔层）；封面 100% 遮光测试合格（强光照射看不见内页字迹，逐个检查并记录） |
| 内容 | 单页卡片：受试者号栏（留空，启用时手写）、**层代码**、**层内分配位序号**、**arm（A/B/C）**、生成日期、独立统计师签名 |
| 编号 | **按层连续编号**：`S1-001…S1-120`、`S2-001…`、`S3-001…`、`S4-001…`；编号与 §3.3 输出的 `slot` **严格一一对应**（即 IWRS 与信封使用同一条序列，杜绝双重分配） |
| 首批制作量 | 每层前 **40** 个分配位（4 层合计 160 个信封）；用至余量 <10 个时追加制作 |
| 封缄 | 胶封 + 骑缝签名（独立统计师）+ 骑缝章（临床研究中心）+ 防拆封贴 |
| 制作与核对 | 独立统计师制作，临床研究中心指定见证人**逐个核对编号连续性与总数**（不拆封），双签，填写附录 A2 |
| 保管 | **临床研究中心**上锁文件柜，按层分格；钥匙由 IWRS 管理员持有，**备份钥匙密封后由临床研究中心质量负责人（不参与本研究）保管**；柜门加装启闭登记本 |
| 存放禁忌 | 不得存放于妇科门诊、针灸科治疗室、研究者办公室或任何研究团队日常可及处 |

### 5.2 启用条件（全部满足方可启用）

1. IWRS 不可用（网络中断、系统故障、平台维护）且**持续 ≥30 分钟**，经 IWRS 管理员或临床研究中心值班电话确认；
2. 受试者已完成**全部** §4.2 步骤 1–3 的前置条件（资格确认、层次判定、基线 QST 与问卷完成），有纸质/EDC 证据；
3. 当日推迟随机会给受试者带来实际不便或导致超出 V1 时间窗（筛选后 14±4 天）；
4. **PI 或其书面授权代表电话/书面批准**并记录批准时间。

> 若上述任一条不满足，**一律推迟随机至系统恢复**。信封是应急手段，不是便利手段。

### 5.3 启用步骤

1. CRC 与第二名研究人员（双人）同时在场；
2. 依据《信封启用登记本》查明**该层已使用的最大分配位序号**，取**下一个连续编号**的信封（如 S2 已用至 S2-013，则取 S2-014）；**不得挑选、不得跳号、不得同时取出多个**；
3. 双人核对信封编号、遮光完整性、封缄未破损，拍照留存（照片含编号与封缄面）；
4. 当场拆封，在卡片上填写受试者号、拆封日期时间、双人签名；
5. 卡片原件立即放回原信封，装入新的"已启用"档案袋，交回临床研究中心上锁保管；卡片复印/扫描件按 §4.2 步骤 5 的限制仅提供给针灸排班员；
6. 填写附录 A3《随机化偏离与信封启用记录表》，48 小时内报 PI 与数据管理员。

### 5.4 次日核对（强制）

- IWRS 恢复后的**下一个工作日内**，IWRS 管理员在系统中为该受试者补录随机记录，系统必须自动取到**同一层同一分配位序号**并给出**同一 arm**；
- 独立统计师核对：信封 arm = IWRS arm、分配位序号一致、时间戳标注"信封补录"及实际拆封时间；
- 不一致 → 立即列为**重大方案偏离**，冻结该层后续随机，由独立统计师排查序列/信封对应关系，PI 报伦理委员会；受试者仍按**首次实际接受的分配**继续，并在 ITT 中按**信封所示分配**分析（以拆封时间戳为准），此规则写入 SAP。

### 6.2 审计轨迹（audit trail）要求

- IWRS 与 EDC 均须启用**不可关闭**的审计轨迹，记录：操作人、时间戳、操作类型、变更前后值、终端标识；
- 审计轨迹**只增不改**，数据库管理员亦不得删除；
- 每月由数据管理员导出随机模块审计轨迹摘要（不含 arm）交临床研究中心质控存档；
- 任何对随机记录的查询式访问（read access）同样记录并纳入月度审查——**"谁看过分配"与"谁改过分配"同等重要**。

### 6.3 不得事后更改

- 分配一经产生，**任何理由**（受试者要求换组、医师认为不合适、层次录错、事后发现不合格）**均不得更改、撤销或与他人调换**；
- 因层次录入错误导致取自错误层的分配位：分配**有效且保留**，按 §7.2 处理；
- 违反本条属重大方案偏离，须报 PI 与伦理委员会，并作为核查发现记录于 TMF。

### 6.4 其他隐藏保障

- 未使用的分配位数量、各层剩余量对 CRC 与研究者不可见；
- IWRS 界面不显示"下一例将是…"类任何提示；
- 治疗室排班遵循 SOP 11：A/B 受试者分时段或屏风隔离，避免相互观察针具与电针仪显示；
- 研究团队不得自行制作任何形式的"分组一览表"（纸质或电子）；针灸科的排班记录仅保留至治疗当日，之后归档至临床研究中心上锁保管。

## 7. 误随机与错分处理

### 7.1 误随机（randomized in error）

**定义**：受试者已被 IWRS/信封分配，但事后发现随机时即不满足纳入或触犯排除标准（如手术记录后续核实为根治性手术、随机前 6 周曾变更激素方案、筛选期 NRS 录入错误等）。

**处理**：
1. 发现者 24 小时内报 CRC 与 PI；
2. PI 从**受试者安全**角度判定是否继续干预：存在安全隐患（如发现凝血功能障碍、植入式电子装置）→ 立即停止针刺/电针，转入安全随访；无安全隐患 → 可由 PI 与受试者共同决定是否继续；
3. **无论是否继续干预，该受试者保留在 ITT 人群，按随机分组分析**（冻结表 §7："ITT（全部随机者，按分配分析）"）；
4. **不得重新随机**、不得将分配位"退回"给后续受试者；
5. 记录于附录 A3 与方案偏离日志；重大者报伦理委员会；
6. per-protocol（PP）人群按 SAP 规则排除（重大方案偏离）。

### 7.2 错分层（wrong stratum）

**定义**：随机时录入的 CSI 分层或激素分层与源数据核实后的真实层次不符。

**处理**：
1. 分配**有效**，受试者按已分配的 arm 继续；
2. 在 EDC 中同时保留 **`STRAT_RAND`（随机时录入的层）** 与 **`STRAT_TRUE`（核实后的真实层）** 两个变量，并记录差异原因；
3. **主分析使用 `STRAT_RAND`**（as-randomised，与随机实施一致，保持 I 类错误控制）；**敏感性分析使用 `STRAT_TRUE`**；此规则由 SAP 预设，不得在揭盲后决定；
4. 该分配位仍计入其被取用的层，不作回退；
5. 记录于附录 A3。

### 7.3 错分/错治（wrong treatment administered）

**定义**：受试者被随机至 A 却接受了 B 的操作（或相反），或 C 臂受试者接受了研究内针刺。

**处理**：
1. 立即停止错误操作，报 PI（24 小时内）；
2. **ITT 分析仍按随机分组**；实际接受的治疗记录于 CRF 治疗记录模块并派生 `TRT_ACTUAL` 变量；
3. 列为**重大方案偏离**，排除出 PP 人群；
4. 由 SOP 11 判定是否构成去盲事件；C 臂受试者接受针刺者，其"研究外针灸"伴发事件按冻结表 §1 estimand 规则处理；
5. 根因分析 + 纠正预防措施（CAPA），全员再培训并记录。

### 7.4 随机后退出

- 受试者随机后退出（拒绝继续治疗、失访、撤回同意）**仍属 ITT 人群**；
- 退出类型必须细分并在 CRF 中分别记录：
  - `WD_TRT`：仅退出干预，同意继续随访与 ePRO；
  - `WD_FU`：退出访视随访，同意继续 ePRO 或电话随访；
  - `WD_ALL`：完全撤回同意（含撤回后续数据收集）——**撤回之前已收集的数据仍纳入分析**，须在 ICF 中明示；
- 退出日期、原因码、是否愿意继续被联系，逐项记录；
- **不得因退出而将其分配位释放给他人**；
- 退出后不再随机化操作。

## 8. 随机化质控

### 8.1 月度分层平衡报告（不暴露分配）

由 IWRS 管理员于每月 5 日前生成、独立统计师复核、报 PI 与临床研究中心，内容**仅限**：

| 报告项 | 说明 |
|---|---|
| 各层累计随机例数（S1–S4） | 只报层内总数，**不分臂** |
| 本月新增随机例数、累计随机例数 vs 计划进度 | 对接第 9 个月招募审计（冻结表 §6：滚动 3 个月 <5 例/月 → 启动协作点预案） |
| 各层剩余可用分配位是否 ≥10 | 触发追加生成 |
| 信封启用次数与次日核对结果 | 全部应为"一致" |
| 随机化偏离例数与类型 | 误随机 / 错分层 / 错治 / 超窗 |
| 基线未完成导致的随机拦截次数 | 反映流程执行质量 |
| 随机至首次治疗的中位间隔（A/B 合并） | 应 ≤3 天 |

**严禁**在该报告中出现：任何臂别计数（含 A+B 合计 vs C）、区组信息、剩余分配位的具体 arm 序列、可反推分组的交叉表。

### 8.2 独立统计师的内部平衡核查（不外发）

- 每 3 个月，独立统计师在加密环境内核查：各层 A:B:C 实际比例是否符合区组预期、是否存在系统性偏离（如某终端总是取到某臂，提示系统缺陷）；
- 结果仅以"未发现异常 / 发现异常已处置"一句话形式写入月度报告，**不附任何数字**；
- 发现系统缺陷立即冻结随机功能并报 PI 与临床研究中心。

### 8.3 与盲态样本量再估计（SSR）的接口

- 入组达 **100 例**时触发盲态 SSR（冻结表 §6）；
- **数据管理员**导出盲态数据集（含主要变量与协变量，**不含 arm、不含 X/Y/Z**），**独立统计师**计算盲态合并标准差（pooled SD）；合并 SD >2.4 时按预设规则上调样本量，**上限 240**，**不做效应量调整**；
- 若样本量上调，本 SOP §3.2 的"每层 ≥120 分配位"已足以覆盖 240 例，**通常无需重新生成序列**；如某层剩余 <10 个分配位，按 §3.2 追加生成；
- SSR 结果只输出"合并 SD 与建议 N"，不得输出任何分臂信息（详见 DMP 与 SAP）。
