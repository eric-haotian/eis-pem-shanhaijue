## 0. 使用说明与 EDC 构建规范

### 0.1 通用约定
| 项 | 规定 |
|---|---|
| 数据采集系统 | 电子 CRF（EDC，临床研究中心平台或经验证的第三方系统），纸质源文件/纸质 CRF 作备份 |
| 变量命名 | 全部英文 snake_case，≤32 字符，首字符为字母；重复表加后缀 `_no` 表示序号 |
| 日期格式 | `YYYY-MM-DD`；部分日期允许 `YYYY-MM`（历史事件，字段名后缀 `_ym`）；时间 `HH:MM`（24 h 制，时区 UTC+8） |
| 缺失编码 | `-9` = 未做/不适用；`-8` = 患者拒答；`-7` = 数据缺失且不可获得。派生变量遇上述值一律置为缺失（不参与计算） |
| 是否型 | `1` = 是，`0` = 否，`9` = 不详（仅在明确允许处使用） |
| 单位 | 长度 cm/mm、体重 kg、压力 kPa、电流 mA、时间 min，单位固定写入标签，不作为可填字段 |
| 受试者标识 | EDC 中仅存 `scr_id` / `subj_id`；姓名、身份证号、住院号、手机号仅存于中心保管的《受试者鉴认代码表》（纸质 + 加密电子），不进入 EDC（个人信息保护法最小必要原则） |
| 电子签名 | 研究者签署（EDC 电子签名符合《药物临床试验电子数据采集技术指导原则》），每模块设 `*_by` / `*_dt` 审计字段（系统自动，不在下表逐一列出） |

### 0.2 EDC 分区与角色权限（盲法保护）
主要对比 A vs B 为双盲（患者与结局评估者），因此 EDC 必须分区：

| 分区 | 包含模块 | 可访问角色 |
|---|---|---|
| **盲态核心区（blinded core）** | 00–10、12–20（除模块 11） | PI、协调员、盲态评估者（仅其录入模块）、盲态数据管理员、盲态统计师 |
| **非盲治疗区（unblinded partition）** | 模块 11（针刺治疗记录，含 mA、假针确认） | 针灸医师（仅本人录入记录）、非盲数据管理员、独立统计师、非盲监查员 |
| **随机分配区（IWRS）** | 分组结果 | IWRS 系统、独立统计师；协调员仅见"是否针刺臂/常规治疗臂"以安排流程 |

- 盲态核心区中，治疗臂字段 `arm_open_label` 只区分 `1` = 针刺治疗臂（A 或 B，不区分）与 `2` = 常规治疗臂（C）；A/B 的真实分配保存在 IWRS 与非盲治疗区。
- 主分析前，统计师取得的数据集中治疗变量以 `X` / `Y` / `Z` 编码（对应关系由独立统计师在盲态数据审查会后揭示）。
- PI 默认处于 A/B 盲态；仅在 SAE 需要时通过 IWRS 破盲程序解盲（模块 16 记录）。

| `ehp_core_total` | 核心问卷总分（5 域均值） | 派生 | `mean(ehp_pain, ehp_control, ehp_emotion, ehp_social, ehp_selfimage)` | 只读 | 任一域缺失则总分缺失 |

> 评分方向：**分数越高、生活质量越差**；`-9`（不适用）条目不计入分子与分母。域—条目对应关系以获授权中文版的官方计分手册为准，EDC 上线前由统计师用 3 份模拟问卷进行计分验证（结果存 TMF）。
