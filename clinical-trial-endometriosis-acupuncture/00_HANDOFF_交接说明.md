## 一、一句话结论

**设计工作已完成且可辩护，但这套文件现在不能直接递交龙华医院。**

阻碍递交的不是"文件写得不够多"，而是包内存在 **76 处占位符（【】）、51 处空白填写位、56 条未核实引用**——其中绝大多数**只能由龙华的人提供**，或**需要能访问 PubMed/ChiCTR 的环境**才能完成。

在这些空缺被填上之前递交，最可能的结果是被科研处或伦理委员会退回，并消耗 PI 在院内的信用。

## 四、给下一个 agent 的硬性约束（**最重要的一节**）

交接给另一个 AI 的最大风险，是它出于"帮忙补全"的意图，把占位符填成**看起来合理但实际是编造**的内容。以下为不可逾越的红线：

| # | 禁止事项 | 原因 |
|---|---|---|
| N1 | **禁止**把 A 类占位符（【】）填成推测值 | 手术量、伦理委员会名称、保险单号等一旦编造，递交时即被发现，PI 承担后果 |
| N2 | **禁止**把 UNVERIFIED 引用改标为 VERIFIED，或补充未经实际打开原文核实的效应量、PMID、页码 | 伦理与期刊层面均属学术不端 |
| N3 | **禁止**改动冻结表中的任何参数（样本量、分配比、主要终点定义、访视窗口、干预参数、层级检验顺序）| 冻结表是唯一上游；改动须走 V1.1 升版流程并同步全部下游文件 |
| N4 | **禁止**在样本量未经可行性核查确认前，把 N=210 表述为"最终样本量" | 文件中已明确标注为 V1.0 暂定值 |
| N5 | **禁止**删除或弱化文件中的诚实性声明（检索受限说明、设计边界声明、把握度不足声明、开放标签声明）| 这些是方案可辩护性的来源，不是缺陷 |
| N6 | **禁止**在任何文件中把机制假说写成已证实结论（尤其"逆转中枢敏化"）| 见 IB §2 措辞纪律 |
| N7 | **禁止**在伦理批准、国家备案、ChiCTR 预注册全部完成前，启动任何人体操作 | 法规要求 |

**如果下一个 agent 遇到无法填写的空缺，正确做法是保留占位符并在交付说明中列出，而不是填满它。**

## 五、建议的执行顺序

```
第 1 步（并行，1–2 周）
  ├─ C4：把可行性核查表转成可填写表格 → 发妇科/针灸科/科研处/临床研究中心
  └─ B1–B3：在有 PubMed 访问的环境完成引用复核

第 2 步（4–6 周）
  ├─ A1：九个变量数据回收 → 作出 GO / MITIGATE / SWITCH 决策
  ├─ A2–A5：针灸科专家共识会（Co-PI、非穴位图、器材、采购）
  └─ A6–A11：科研处对接（模板、伦理、保险、备案要求）

第 3 步（决策点）
  └─ 冻结表升版 V1.1 → 若样本量或设计有变，同步修订全部下游文件

第 4 步（2–3 周）
  ├─ C1：格式转换与排版
  ├─ C5：伦理答辩材料
  └─ 递交科研处立项 → 外部专家科学性审查 → 伦理

第 5 步
  └─ 伦理批准 → 备案（≥启动前 30 日）→ ChiCTR 预注册 → 假针预试验 → 首例入组
```

**第 3 步是不可跳过的决策点。** 在此之前递交的任何版本都是不完整的。
